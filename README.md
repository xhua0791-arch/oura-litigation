# Oura 美国专利诉讼 · RINGWATCH

响应式专利诉讼研究看板，包含筛选、案件详情、专利关系图、时间轴及JSON导出。

检索快照：2026-10-30。67项程序、60件已识别专利；并非穷尽清单，最新状态以各案原始案卷为准。风险等级均待评估。

公开内容包含案件摘要、专利及程序信息、来源链接和本地证据文件名索引；不含原始PDF。

## 发布
在 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions，再运行 Publish RINGWATCH 工作流。

## 本地使用
打开 dist/index.html 即可运行，无需安装依赖。所有静态资源使用相对路径。
